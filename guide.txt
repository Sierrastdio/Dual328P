3. Kubuntu (Ubuntu KDE) 환경
쿠분투는 패키지 관리자가 강력해서 과정이 훨씬 단순하고 직관적입니다. 특히 씽크패드 X1 카본에서 터미널(Konsole)을 쓰시면 아주 쾌적할 거예요.

① avrdude 설치
쿠분투에서는 경로를 찾아다닐 필요 없이 시스템 전역에 avrdude를 설치해버리는 게 가장 편합니다.

F4나 Ctrl + Alt + T를 눌러 Konsole을 켭니다.

아래 명령어로 설치합니다.

Bash
sudo apt update
sudo apt install avrdude
② 사용자 권한 설정 (중요)
리눅스에서는 USB 포트 접근 권한이 필요합니다. 현재 사용자를 dialout 그룹에 추가해야 나중에 sudo 없이도 쓸 수 있습니다.

Bash
sudo usermod -a -G dialout $USER
(명령어 입력 후 로그아웃했다가 다시 로그인해야 적용됩니다.)

③ 퓨즈 비트 굽기
리눅스에서는 포트 이름이 COM이 아니라 /dev/ttyACM0 또는 /dev/ttyUSB0 형태입니다.

포트 확인: 우노를 꽂은 상태에서 ls /dev/ttyACM* 또는 ls /dev/ttyUSB*를 쳐서 이름을 확인하세요.

연결 확인:

Bash
avrdude -c avrisp -p m328p -P /dev/ttyACM0 -b 19200 -v
16MHz CKOUT 설정:

Bash
avrdude -c avrisp -p m328p -P /dev/ttyACM0 -b 19200 -U lfuse:w:0xBF:m
💡 요약 및 팁
Windows: AppData 폴더 안의 깊숙한 경로로 cd 해서 들어가서 실행해야 함.

Kubuntu: sudo apt install avrdude 한 번이면 어디서든 avrdude 명령어를 바로 쓸 수 있어 훨씬 편함.

성공 확인: 굽기가 끝나면 나노(B)의 **8번 핀(D8)**을 오실로스코프로 찍어보세요. 코드를 넣지 않았는데도 16MHz 사각파가 나오고 있다면 성공입니다.

이제 씽크패드에서 쿠분투 터미널 열고 바로 작업 시작해보시면 되겠네요! 리눅스 환경에서 avrdude 관련해서 권한 에러(Permission denied)가 나면 당황하지 마시고 명령어 앞에 sudo를 붙여보세요. 조립 전 마지막 관문입니다. 파이팅입니다!

1. 타겟 칩(Core 1, 2)의 퓨즈 비트 설정 (가장 중요)
클럭을 받는 쪽 칩들도 우노(라이터)에 연결해서 아래 명령어를 한 번씩 실행해줘야 합니다.

설정값: Low Fuse를 0xE0 (External Clock 모드)로 변경

명령어 (쿠분투 기준):

Bash
avrdude -c avrisp -p m328p -P /dev/ttyACM0 -b 19200 -U lfuse:w:0xE0:m
이유: 이렇게 설정해야 칩 내부의 발진 회로가 꺼지고, XTAL1 핀이 순수하게 외부 신호를 받아들이는 **'입력 전용 핀'**으로 작동합니다.

2. 하드웨어 연결 시 주의점
작성하신 표대로 74HC125를 거쳐서 연결하신다면 아래 사항만 지키시면 됩니다.

XTAL2(10번 핀)는 비워두기: 외부 클럭(사각파)을 넣을 때는 10번 핀에 아무것도 연결하지 않습니다. (N/C 처리)

GND 공통화: ACG 나노와 타겟 328P 칩들의 GND는 반드시 하나로 묶여 있어야 합니다. 25cm 선을 쓰시니까 GND 선도 클럭 선과 같이 꼬아서 보내는 게 좋습니다.

0.1uF 커패시터: 타겟 칩의 VCC-GND 바로 옆에 꼭 붙여주세요. 클럭이 외부에서 들어오면 칩이 전기를 더 예민하게 소모합니다.

3. 왜 굳이 퓨즈를 또 건드려야 할까?
기본 아두이노 설정(External Crystal)은 칩 스스로 전기를 보내 크리스탈을 떨게 만드는 방식입니다. 그런데 우리가 74HC125로 강한 16MHz 신호를 밀어 넣으면 내부 회로와 충돌이 생겨 신호가 찌그러질 수 있습니다. 0xE0 설정은 이 충돌을 막고 외부 신호를 가장 깨끗하게 받아들이는 모드입니다.

💡 요약하자면
ACG 나노: 0xBF로 구워서 클럭을 뿜어내게 만든다. (성공하심)

타겟 칩들: 0xE0으로 구워서 클럭을 받아먹게 만든다. (이 작업이 남았습니다)

연결: ACG D8 → 74HC125 → (25cm 선) → 타겟 XTAL1.

이렇게 하면 25cm라는 긴 거리와 2cm의 편차 속에서도 두 칩이 완벽하게 동기화되어 16MHz로 질주하게 됩니다. 이제 타겟 칩들 퓨즈 설정만 마무리하시면 하드웨어 준비는 끝입니다! 바로 진행해 보시겠어요?

## [Step 1] 클럭 제너레이터(나노) 퓨즈 비팅 연결 (ISP)

| 우노 (A: 라이터) | 나노 (B: 생성기) | 나노 물리 핀 번호 | 비고 |
|:---|:---|:---|:---|
| **5V** | **5V** | 27번 (5V) | 전원 공유 |
| **GND** | **GND** | 4번 or 29번 (GND) | 그라운드 공유 |
| **D10** | **RESET** | 28번 (RST) | 타겟 리셋 제어 |
| **D11** | **D11** | 14번 (MOSI) | 데이터 송신 |
| **D12** | **D12** | 15번 (MISO) | 데이터 수신 |
| **D13** | **D13** | 16번 (SCK) | 데이터 클럭 |
